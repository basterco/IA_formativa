# Propuesta de investigación: brecha digital de conocimiento en el uso de la IA (SENA)

Sitio web de la propuesta de investigación-acción participativa sobre la brecha digital de conocimiento en el uso de la inteligencia artificial en procesos formativos inclusivos del SENA.

## Contenido

| Archivo | Descripción |
|---|---|
| `index.html` | Página principal: los ocho apartados de la guía, Asesor IA, Validador, Recursos y Equipo |
| `asesor_ia_formacion_inclusiva.html` | Asesor de IA independiente (simulación y OpenAI con API Key propia) |
| `validador_preguntas_openai.html` | Validador de preguntas independiente (simulación y OpenAI con API Key propia) |
| `ruta_metodologica_propuesta.png` | Ruta metodológica (figura 1) |
| `docs/` | Propuesta en PDF y Markdown |

## Funciones según el lugar donde se abra

| Función | En GitHub Pages | Dentro de Claude |
|---|---|---|
| Propuesta, búsqueda, citas, Gantt, mapa | Sí | Sí |
| Asesor y Validador en modo simulación | Sí | Sí |
| Consulta con Claude | Abre claude.ai con la pregunta preparada | Responde dentro de la página |
| Versiones con OpenAI | Sí, con API Key propia | Se descargan como archivo |
| Recursos (subir archivos) | No | Sí |

## Seguridad

- Ningún archivo contiene claves de API.
- Si usa los modos con OpenAI, la clave queda expuesta en el navegador: úsela solo para pruebas personales y con límite de gasto. Para uso institucional se requiere un backend intermediario.
- No ingrese datos personales de aprendices ni información institucional reservada.
